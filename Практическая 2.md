1. **Задача:** Вычислите результат выражения `int x = 17 / 5; int y = 17 % 5;`.
   _Ответ:_ `x = 3`, `y = 2`.
```csharp

            Console.WriteLine($"X = {x}");
            Console.WriteLine($"Y = {y}");
```
2. **Задача:** Каково значение `res` после выполнения `int a = 5; int res = ++a * 2;`?
   _Ответ:_ `res = 12` (префиксный инкремент увеличивает `a` до 6, затем умножение).
```
            Console.WriteLine("Вычислите значение res");

            int a = 5;
            int res = ++a * 2;

            Console.WriteLine($"res = {res}");
```
3. **Задача:** Каково значение `res` после выполнения `int a = 5; int res = a++ * 2;`?

```
            Console.WriteLine("Значение res: ");

            int a = 5;
            int res = a++ * 2;

            Console.Write($"res = {res}");
```

### 3.3. Логические операторы

1. **Задача:** Вычислите: `!true || false && true`.
   _Ответ:_ `false` (приоритет: `!` -> `&&` -> `||`: `false || false` дает `false`).
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;

namespace _3._3.Логические_операторы
{
    internal class Program
    {
        static bool Foo()
        {
            Console.WriteLine("Foo вызван");
            return true;
        }

        static void Main(string[] args)
        {

            bool res = !true || false && true;
            Console.WriteLine($"{res}");
```
2. **Задача:** Будет ли вызван метод `Foo()` в `false && Foo()`?
   _Ответ:_ Нет, благодаря короткому замыканию оператора `&&`.
```
            bool res = false && Foo();
            Console.WriteLine($"{res}");
```
3. **Задача:** Будет ли вызван метод `Foo()` в `false & Foo()`?
   _Ответ:_ Да, побитовое/строгое логическое `&` вычисляет оба операнда.
```
            bool res = false & Foo();
            Console.WriteLine($"{res}");
```
4. **Задача:** Вычислите результат: `true ^ false ^ true`.
   _Ответ:_ `false` (`true ^ false = true`, затем `true ^ true = false`).
```
            bool res = true ^ false ^ true;
            Console.WriteLine($"{res}");
```
5. **Задача:** Что вернет выражение `!(5 > 2 || 3 < 1)`?
   _Ответ:_ `false` (`5 > 2` истинно, внутри скобок `true`, отрицание дает `false`).
```
            bool res = !(5 > 2 || 3 < 1);
            Console.WriteLine($"{res}");
```
6. **Задача:** Дано: `bool a = true, b = false;`. Чему равно `a && !b || b && !a`?
   _Ответ:_ `true` (`true && true || false && false` -> `true || false` -> `true`).
```
            bool a = true, b = false;
            bool res = a && !b || b && !a;
            Console.WriteLine($"{res}");
```
7. **Задача:** Каков результат `true || (x / 0 == 1)` при любом целом `x`?
   _Ответ:_ `true` (деление на ноль не произойдет из-за короткого замыкания `||`).
```
            int x = 5;
            bool res = true || (x / 0 == 1);
            Console.WriteLine($"{res}");
```
8. **Задача:** Каков результат `false & (10 / 0 == 1)`?
   _Ответ:_ Выбросится исключение `DivideByZeroException`, так как `&` обязательно вычисляет правый операнд.
```
            int zero = 0;
            bool res = false & (10 / zero == 1);
            Console.WriteLine($"{res}");
```
9. **Задача:** Чему эквивалентно выражение `!(A && B)` по закону де Моргана?
   _Ответ:_ `!A || !B`.
```
            bool A = true, B = false;
            bool deMorgan1 = !(A && B);
            bool deMorgan1Equivalent = !A || !B;
            Console.WriteLine($"{deMorgan1}, {deMorgan1Equivalent}");
```
10. **Задача:** Чему эквивалентно выражение `!(A || B)` по закону де Моргана?
    _Ответ:_ `!A && !B`.
```
            bool A = true, B = false;
            bool deMorgan2 = !(A || B);
            bool deMorgan2Equivalent = !A && !B;
            Console.WriteLine($"{deMorgan2}, {deMorgan2Equivalent}");
        }
    }
}
```

### 3.4. Побитовые операторы и сдвиги

1. **Задача:** Чему равен результат `5 & 3` в двоичном и десятичном виде?
   _Ответ:_ `0101 & 0011 = 0001` (десятичное `1`).

2. **Задача:** Чему равен результат `5 | 3`?
   _Ответ:_ `0101 | 0011 = 0111` (десятичное `7`).
```
            int x = 5 | 3;

            Console.WriteLine($"{x}");
```
3. **Задача:** Чему равен результат `5 ^ 3`?
   _Ответ:_ `0101 ^ 0011 = 0110` (десятичное `6`).
```
            int x = 5 ^ 3;
            Console.WriteLine($"{x}");
```
4. **Задача:** Вычислите `~0` для типа `int`.
   _Ответ:_ `-1` (все биты устанавливаются в 1, что в дополнительном коде равно `-1`).
```
            int x = ~0;
            Console.WriteLine($"{x}");
```
5. **Задача:** Чему равно `1 << 4`?
   _Ответ:_ `16` ($1 \times 2^4$).
```
            int x = 1 << 4;
            Console.WriteLine($"{x}");
```
6. **Задача:** Чему равно `40 >> 2`?
   _Ответ:_ `10` ($40 / 2^2$).
```
            int x = 40 >> 2;
            Console.WriteLine($"{x}");
```
7. **Задача:** Как с помощью побитовой операции проверить, установлен ли третий бит числа `n` (маска $2^3 = 8$)?
   _Ответ:_ `(n & 8) != 0` или `(n & (1 << 3)) != 0`.
```
            int n = 13;
            bool x = (n & 8) != 0;
            bool y = (n & (1 << 3)) != 0;
            if (x)
            {
                Console.WriteLine("3-й бит установлен");
            }
            else
            {
                Console.WriteLine("3-й бит не установлен");
            }
```
8. **Задача:** Как с помощью побитовой операции установить 2-й бит числа `n` в 1?
   _Ответ:_ `n = n | (1 << 2);` (или `n |= (1 << 2);`).
```
            int n = 8;
            n |= (1 << 2);
            Console.WriteLine(n);
```
9. **Задача:** Как сбросить (установить в 0) 4-й бит числа `n`?
   _Ответ:_ `n = n & ~(1 << 4);` (или `n &= ~(1 << 4);`).
```
            int n = 20;
            n &= ~(1 << n);
            Console.WriteLine($"{n}");
```
10. **Задача:** Каков результат выражения `(-16) >> 2` для `int`?
    _Ответ:_ `-4` (арифметический сдвиг вправо сохраняет знаковый бит 1).
```
            int x = (-16) >> 2;
            Console.WriteLine($"{x}");

        }


    }
```

### 3.7. Операторы типов и приведения

7. **Задача:** Что вернет выражение `object x = null; bool b = x is null;`?
   _Ответ:_ `true`.
```
            object x = null;
            bool b = x is null;
            Console.WriteLine($"{b}");
```
8. **Задача:** Каков результат `(int)3.99`?
   _Ответ:_ `3` (дробная часть отсекается без округления).
```
            int res = (int)3.99;
            Console.WriteLine($"{res}");
```
9. **Задача:** Каков результат pattern matching:
   ```csharp
   object o = 42;
   if (o is int val && val > 40) { ... }
   ```
   Будет ли выполнено тело блока?
   _Ответ:_ Да, `val` получит значение 42, условие `val > 40` истинно.
```
            object o = 42;
            if (o is int val && val > 40)
            {
                Console.WriteLine($"val = {val}");
            }
```
10. **Задача:** Что вернет выражение `default(int)` и `default(string)`?
    _Ответ:_ `0` и `null`.
```
            Console.WriteLine($"{default(int)}, {default(string) ?? "null"}");
        }
    }
```
